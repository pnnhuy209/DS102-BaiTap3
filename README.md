# DS102 - Linear Regression

Bài thực hành Linear Regression trên bộ dữ liệu Forest Fires của UCI.

Nội dung:

- Xây dựng Linear Regression bằng NumPy.
- Đánh giá bằng MAE, MSE, RMSE và R².
- Chuẩn hóa dữ liệu về trung bình 0 và phương sai 1.
- Loại các cột phụ thuộc tuyến tính.
- So sánh mô hình NumPy với Scikit-learn.

Notebook chính: `assignments.ipynb`.

Dữ liệu: `data/forestfires.csv`.
